# SoloEnt 仙侠首章正文盲评

这套评测要求同一模型根据同一份暗黑西游仙侠章纲独立写三篇约 3000 字的第一章，再由真人评审匿名打分。
主成绩是评审独立填写的 0–10 分“总评分”均值，不由五个解释维度加权计算。

来源报告发布于 2026-08-10，覆盖 10 个模型、30 篇匿名作品和 117 份有效评分。报告、题面、方法、
原始作品与评语都钉死在 `SoloEnt-AI/novel_benchmark` commit
`46c5573259dd1802c808a4063899e99bd8e1f54c`；本目录不复制 30 篇来源正文或评语。

## 如何提交一次新运行

1. 用同一个参评模型按 `eval.yaml` 的题面独立生成三次，每次都从空上下文开始。
2. 分别保存三份完整 UTF-8 正文，不做人工修改，并计算各自 sha256。
3. 按 `tasks/README.md` 填写清单后执行：

```bash
node evals/soloent-prosewriting-xianxia/pack-to-result.mjs <submission.json> --out <result.json>
```

转换器只做本地、确定性的结构与证据检查，不联网、不调用模型、不打分。它会输出 `score: null`；评测作者在核验三份正文、
匿名化与评审证据后，按 `eval.yaml` 公示的同一流程补入总评分。三份正文不齐、sha256 不符、文件不是 UTF-8 文本或清单越界时，转换器直接失败。

## 官方结果怎么读

`published-results/official-report-2026-08-10.json` 转录来源报告。EvalHub 注册表能可靠映射的 6 个模型进入数值成绩列表；
另外 4 个来源模型没有对应注册项，仍原样保留在“完整官方榜单”辅助表中，但不会被改名映射到其他模型。

这些是来源方发表值，不是 EvalHub 独立复跑。每个模型只有三篇，来源报告明确指出第一档差异不具统计显著性；
这套榜单更适合观察档位、维度和稳定性，不适合把百分位级差距解释成确定胜负。
