# SoloEnt 网文写作全流程 18 模型横评

这套评测不只让模型写一章，而是让它从一条粗略创意开始，完成 Plan 需求沟通、策划文件、章纲和第一章正文。
每个模型在三个独立空项目中各跑一次，首章落盘即停；真人编辑只看匿名第一章，按百分制评分，有效首章均分是主成绩。

来源报告发布于 2026-07-07，覆盖 18 个模型、54 次运行、53 篇有效首章和 470 个落盘材料文件。
全部证据钉死在 `SoloEnt-AI/novel_benchmark` commit `46c5573259dd1802c808a4063899e99bd8e1f54c`。

## 如何提交新运行

按照 `eval.yaml` 的 `prompt` 与 `run_spec` 在三个独立 SoloEnt 空项目中执行。每次保存完整首章和过程证据；
未生成完整首章时记录失败原因。按 `tasks/README.md` 填写清单后运行：

```bash
node evals/soloent-writingflow-18models/pack-to-result.mjs <submission.json> --out <result.json>
```

转换器只核验三次尝试、有效正文、失败说明和证据指纹，不联网、不调用模型、不打分，结果保持 `score: null`。
评测作者核对流程和停止条件后，把有效首章匿名交给真人编辑，并补入有效分数的算术平均。

## 分数边界

主成绩只是真人编辑对第一章的百分制盲评。引导互动、结构设计和执行遵从是独立的 5 分制过程评分，不能与主成绩换算或合并。
来源模型分五批评阅，编辑和时间可能不同，个位数差距只适合看大致档位。

官方结果文件保留完整 18 行来源榜单。13 个能与 EvalHub 注册表可靠对应的模型进入数值成绩列表；
另外 5 个只在辅助表中原样展示，不伪造映射。
